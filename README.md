# SemesterProject2 – GoodBid

## Description

This project is the second semester project for Front End development at Noroff.

At GoodBid you can register or login as long as you have a noroff email address. You can create new listings and make bids on other users listings.

## Hosted site

[https://goodbid.netlify.app/](https://goodbid.netlify.app/)

## Tech stack

- **HTML5 + SCSS**
- **JavaScript (ES Modules)**
- **Bootstrap 5**
- **FontAwesome (icons)**
- **Noroff API V2 - Auction House API**
- **Deployed with Netlify**

## Getting started

### Installing

It is easy for you to get this project started:

1. Clone the repository:

```bash
git clone git@github.com:VReinhaug/SemesterProject2
```

2. Install the dependencies:

```
npm install
```

### Running

To run the app, run the following command:

```
npm run start
```
